Everything here runs on it — Docs, blog, portfolio sections, dark mode,
SPA navigation, and full theme overrides via plain CSS variables.

## Highlights

- Zero dependencies, zero build
- Components as replaceable plain JS
- Sections compose a rich homepage
- Port auto-increment when busy
